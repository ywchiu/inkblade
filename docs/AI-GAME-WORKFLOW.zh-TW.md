# 用 AI 製作《墨刃》：簡明流程

[English](AI-GAME-WORKFLOW.en.md) · [回到遊戲介紹](../README.md)

《墨刃》把 AI 生成的圖片、3D 角色和聲音，整合成可以操作、對戰、推進故事的瀏覽器遊戲。製作時依序完成以下工作：

1. **決定玩法。** 主角是鍾馗，玩家可單挑或沿地圖闖關，依序面對狼、劍客與山魈。先確定移動、攻擊、閃身和防禦要怎麼操作。
2. **做視覺參考。** 用 GPT Image 設計鍾馗和古寺，用 Nano Banana 2.1 製作其他角色的參考圖。讓服裝、色彩和世界觀一致。
3. **做角色模型。** 用 Tripo H3.1 將角色參考圖轉為 3D 模型，再檢查正背面、比例和材質。
4. **做成遊戲。** 用 JavaScript 和 Three.js 放入場景與角色，製作動作、攻擊判定、敵人行為、關卡和介面。這一步讓生成素材真正可以遊玩。
5. **加入聲音與故事。** 寫出《借名山》的角色對白，用 ElevenLabs 語音模型配音，再加入配樂與音效。
6. **反覆試玩。** 在瀏覽器測試操作、戰鬥、故事和手機畫面，依實際感受調整。用 `npm run check`、`npm test` 檢查程式。

遊戲畫面和實際戰鬥 GIF 在 [README](../README.md)。遊玩只需啟動本機程式；重新生成 AI 素材才需要相關服務帳號。
