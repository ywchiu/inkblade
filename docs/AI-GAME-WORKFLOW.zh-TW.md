# AI 製作 3D 遊戲：墨刃實作案例

[English](AI-GAME-WORKFLOW.en.md) · [遊玩與安裝](../README.md)

這是一個可遊玩的 3D 瀏覽器原型。AI 協助製作美術參考、角色網格與聲音；戰鬥規則、骨架動作、關卡、輸入、介面與整合由 JavaScript 實作。概念圖完成不等於遊戲完成，必須在實際鏡頭下驗證模型、動作和手感。

## 製作步驟

1. **先定可玩的範圍。** 雨夜古寺、鍾馗主角、狼／劍客／山魈三類對手、一條短篇無雙征途與單挑。核心操作收斂成攻擊、閃身、防禦三顆動作鍵。
2. **生成一致的美術參考。** GPT Image 用於主角與古寺概念；Nano Banana 2.1 用於山魈、劍客和狼的建模參考。檢查輪廓、服裝、材質與配色。這些仍是 2D 圖片。
3. **製作 3D 角色。** 以 Tripo H3.1 將參考圖轉為四個含貼圖的 GLB。用預覽頁檢查正背、比例、朝向、貼圖與網格。
4. **接入動作與場景。** Three.js 載入模型；執行時建立骨架與權重，由程式驅動步伐、揮刀、狼四足奔跑、閃躲、受擊與倒地。古寺、特效及相機也是程式製作。
5. **讓戰鬥真的可讀。** 戰鬥模擬與渲染分離，實作射程、命中時間、精力、架勢、敵人起手、碰撞、招式差異及關口。狼只用近戰。整條路線要實際通關，不能只看單次揮刀畫面。
6. **加故事與表演。** 原創《借名山》把狼、守橋劍客與偽山神串成因果。Higgsfield／ElevenLabs 生成 37 句中文配音、六組固定聲線。發現求救像念稿後，35 句角色對白加入逐句情緒與發聲提示重新生成；長喊話的字幕會等語音播完。
7. **在遊戲內驗收。** 執行 `npm run check`、`npm test`，再用真實瀏覽器驗鍵盤、滑鼠、觸控版面、命中扣血、關卡推進和配音。README 的截圖及 GIF 取自實際運行畫面。

## 程式入口

`dist/game3d.js` 處理流程和輸入；`dist/combat3d.js`、`dist/campaign3d.js` 處理戰鬥；`dist/characters3d.js`、`dist/world3d.js` 負責 3D；`dist/story3d.js` 保存原創對白；`dist/dialogue-audio.js` 播放配音；`tests/` 為行為測試。`art/direction/` 保留精選美術參考。原始供應商回執、帳號資訊與雲端素材網址留在本機，不放進公開倉庫。

遊戲執行不需 AI API key；若要重新生成素材，須另備服務帳號與額度。此專案展示的是 AI 素材如何經過檢查、修整與程式整合成可玩的遊戲，不是單一提示詞直接產出完整作品。
