# 第二關「寒聲嶺」與關卡成長：設計

2026-11-21

## 意圖

使用者想把遊戲做長：更多關、更多故事、更多怪物，主角也要跟著成長。

- **關卡的定義**：一個魔王就是一關，一關是一個新地方。
- **總規模**：目標四到五個魔王，每個魔王是一道不同的題。
- **做法**：一次做完一整關，上線、玩過之後再決定下一關。

這份文件涵蓋兩件事：讓多關成立的地基，以及第二關「寒聲嶺」的完整內容。第一關的內容就是現在的借名山（無名村到鎮祟寺，十章，終點是山魈和無名之主），這次不改。

## 目標

1. **關卡制**：借名山是第一關，寒聲嶺是第二關，兩關是不同的地方，不是同一條路接下去。
2. **存檔**：記住通過了哪些關、拿到了哪些本事。重新整理或隔天再開都還在。
3. **選關**：開始畫面能選已解鎖的關。第二關在第一關通關前是鎖住的。
4. **成長**：打倒每一關的魔王得到一件新本事，下一關魔王的破法要用到它。
   - 第一關的魔王（無名之主）給「喚名」。
   - 第二關的魔王（凍聲婆）給「寒聲」。
5. **寒聲嶺**：四到五章的雪地山路、雪地場景、約三種新怪、魔王凍聲婆，以及整段劇情（各章開場與收尾、魔王開場與結局、志怪錄頁面），附英文翻譯。

## 非目標

- **第三關以後**：寒聲給第三關用，但第三關本身這次不做。
- **等級、經驗值、裝備、技能樹**：都不做。
- **配音**：現在遊戲的配音是關掉的（`VOICE_ON=false`），新台詞和現狀一樣只做字幕。
- **重做第一關**：只為了讓它能結束成「一關」並給出喚名，才去改它的結尾。

## 反目標（做到了也算失敗）

- **魔王能被硬砍打倒**：破法變成可有可無。凍聲婆的冰甲在破法完成前，刀砍必須完全無效，不能只是減傷。
- **破法變成卡關謎題**：玩家站在冰甲前不知道該做什麼。必須有引導，包括劇情台詞、看得見的冰鈴、魔王提示列的文字，以及第一次揮刀無效時的明確回饋。
- **主角強到戰鬥沒難度**：本事是解題工具，不是全面加攻擊力。
- **手機操作變擠**：三鍵加兩個輔助鈕的配置不能被新本事撐亂；在 390×664 的直向畫面也要放得下、不重疊。
- **拖慢第一關**：第一次玩的人不需要多下載任何雪山的東西。

## 限制

- **部署與技術**：純靜態網站，沒有建置步驟，`main` 一更新 Cloudflare Pages 就自動部署。程式在 `dist/`，three.js 0.187 已內附。
- **場景**：全部用程式畫（`dist/journey-scenery3d.js`），沒有場景美術素材。雪山照同樣方式做，風格保持水墨。
- **測試**：`npm test`（node --test）必須全過。新模組要加進 `package.json` 的 `check`。
- **翻譯**：每一句會出現在頁面上的中文，都要在 `dist/lang-en.js` 有對應的英文。
- **介面**：介面上不能有 emoji，iOS 會把 ↗ 之類的符號畫成彩色 emoji；圖示用內嵌 SVG。
- **故事口吻**：沿用第一關的白話口語，原創志怪，不引用古籍原文、不冒稱古籍出處（見 `docs/story-direction.md`）。

## 考慮過的做法

1. **一次做完一整關（選定）**：先打地基（存檔、成長、選關），再把寒聲嶺從路到魔王到劇情整個做完。
   - 好處：每關上線時都是完整的，做完一關就能玩、再決定下一關。
   - 代價：後面幾關要等。
2. **四關一起搭骨架**：四個地方同時開工，每關先兩三章，怪物換色沿用。
   - 好處：很快看到整個故事的輪廓。
   - 代價：每關都薄、魔王容易雷同，之後要全部回頭補。
3. **只做魔王連戰**：打完山魈直接進四個魔王場地。
   - 好處：最省工。
   - 代價：「更多怪」和「去新地方」的感覺很弱，違背使用者要的東西。

使用者選了第一種。

## 使用者已決定的

- 一個魔王一關，一關一個新地方。總共四到五關，一次做一關。
- 成長方式是打倒魔王得到一件新本事，下一關魔王的破法用到它。
- 第二關是雪山，案子照下面「寒聲嶺」一節的方向走。
- 凍聲婆和三種新怪都做新模型，不沿用舊身體（見「模型」一節）。

## 寒聲嶺

### 案子

借名山被偽神借走的名字，有一部分被賣了出去，雪嶺上的凍聲婆是買主之一。她收走山谷裡人的聲音，凍在冰柱與冰鈴裡；村民哭不出聲，也喊不了亡者的名字。鍾馗收到的狀紙是一個啞女畫的。

主線伏筆：偽神把名字賣給了誰。這條線串起之後的每個魔王，所以寒聲嶺的結局要點出下一個買主的線索，但不揭曉。

### 破法

- 凍聲婆把偷來的聲音結成冰甲，冰甲在時刀砍不入。
- 場地四周掛著冰鈴，每個冰鈴封著一個人的聲音。
- 靠近冰鈴用「喚名」叫出鈴裡那人的名字，冰鈴就碎、聲音回去，冰甲跟著裂一部分。
- 冰鈴全碎後冰甲脫落，進入正常的對決，凍聲婆也會變得更兇。
- 打倒她得到「寒聲」。

### 章節

我的提議，章數與內容可調：

1. **啞村**：村口與啞女，冰狐從雪裡竄出。
2. **風雪坡道**：被凍住的旅人醒來擋路。
3. **冰湖**：混合的敵群，加一隻精英吼風山魈。
4. **聲窟前**：最後的敵群。
5. **聲窟**：魔王凍聲婆。

全長約借名山的一半。每章結束有關口，沿用第一關的關口、檢查點和重試規則。

### 新怪

我的提議，數值和招式交給實作的人：

- **冰狐**：四足，小、快、偏白，從雪裡冒出來。
- **凍旅人**：人形，慢；倒下時碎成一圈冰，踩到會被拖慢。
- **吼風山魈**：比山魈小一號的人形獸；會朝前方吼出一道風雪把人推開。精英怪。

四者都有自己的新模型，見「模型」一節。

### 模型

使用者決定：凍聲婆、冰狐、凍旅人、吼風山魈都做新模型。

- **製作流程**：沿用專案過去的做法（`art/direction/roster/README.md`、`art/direction/rigged/README.md`）。
  1. 先生成參考圖。
  2. 圖轉 3D。
  3. 轉正，面朝 +Z。
  4. 需要時綁骨並加動作片段。
- **先估價**：每一步花點數之前，先把預估點數給使用者確認。
- **參考圖先過目**：參考圖先給使用者看過，再轉 3D。
- **動作的來源**
  - 冰狐：四足，比照墨狼與石獸用程式動作，不必付費綁骨。
  - 凍旅人、吼風山魈：可以用程式骨架（比照最早的無相劍客），也可以付費綁骨。由實作的人依效果和點數提出建議。
  - 凍聲婆：魔王，要有正式綁骨的動作片段，至少包括待機、移動、兩到三種攻擊、受擊、倒地。
- **按關載入**
  - 現在 `world3d.js` 在開場就把所有外皮下載完。改成進到哪一關才載入那一關的模型。
  - 第一次玩的人下載量不能比現在多。
  - 模型還沒載完或載入失敗時，照現有的退路，先穿原本的身體與該角色的顏色，遊戲不能卡住。
- **檔案大小**：比照現有角色，貼圖壓縮後每個模型控制在幾 MB 內，具體預算由實作提出。
- **風格**：水墨志怪，與鍾馗、墨狼、無相劍客放在同一個畫面裡不突兀；在雪地上要和地面分得開，不能白成一片。

### 場景

- 雪地取代雨：下雪不下雨，地面是雪，霧偏冷色。
- 路邊有凍住的旅人、雪松、冰湖面。終點聲窟裡掛滿冰鈴。
- 手機上要看得清楚：雪地很亮，敵人、紅色危險區、血條在雪地上都要辨認得出來。

## 成長與本事

- **喚名**（打倒無名之主得到）
  - 對冰鈴：碎鈴。
  - 對一般敵人：短暫定住有名字的魂（例如凍旅人），讓它在第一關以外也有用。
  - 消耗墨氣、有冷卻；確切數值由實作決定。
- **寒聲**（打倒凍聲婆得到）
  - 一聲吼，震住周圍的敵人一小段時間。
  - 這次就要做出來並能使用，讓獎勵當下就感覺得到；它在第三關的解題用途以後再設計。
- **生效範圍**：擁有的本事在每一關都能用，包括回頭重玩第一關。
- **操作**
  - 手機：在現有的輔助鈕列（飲藥、絕技）加上本事按鈕，只在擁有後出現。
  - 鍵盤：新增按鍵，由實作決定用哪個鍵，並寫進操作說明。
- **收集品**（我的提議，使用者未確認，可拿掉）：每一關收齊該關的隱藏收集品，永久增加一點血量上限。這是小補強，不能影響魔王的破法。

## 存檔與選關

- **存檔內容**：通過的關卡、擁有的本事、收集品帶來的強化，存在瀏覽器本機。
- **無法存檔時**：存取失敗照樣能玩，只是不保存，這和志怪錄現在的做法一致。
- **選關畫面**
  - 第一次玩的人看到的跟現在一樣，只有一張「開始征途」卡。
  - 通關第一關後，開始畫面列出兩關；第二關的卡上寫它的名字和一句引子。
- **第一關的新結尾**：無名之主倒下後，結局台詞多一段，交代「名字被賣了出去」並給出喚名，然後回到選關。
- **志怪錄**：分關收錄，第二關的頁面在到達前不揭露。

## 交給實作的人

- 路線座標、每章敵人數量與站位、所有數值。
- 新怪與凍聲婆的招式節奏、雪地特效、場景擺設。
- 程式結構。我的建議是：現在 `dist/journey3d.js` 把唯一一條路寫成全域常數，場景、小地圖、戰役邏輯都直接讀它；改成「一關一份資料」，傳給這些模組，第一關的資料原封不動搬進去。
- 鍵盤按鍵、存檔格式、測試寫法。

## 驗收

- `npm test`、`npm run check` 全過。
- 第一關照舊能從頭打到尾，結尾多出喚名與選關。
- 在瀏覽器實際打通第二關，包括用喚名破冰甲、打倒凍聲婆、拿到寒聲。
- 手機直向 390×664 和 390×844 的截圖要看過：新按鈕、雪地上的介面、冰鈴提示都清楚，沒有重疊、沒有水平溢出。
- 英文模式下第二關沒有漏翻的字（`misses` 為空）。

## 審閱後補上的決定（我的決定，可改）

- **已經通關的老玩家算通過第一關**
  - 現在沒有存「通關」，但志怪錄（`inkblade.journal.v1`）會記下結局頁，跳過也算。
  - 存檔第一次讀取時，若志怪錄有結局頁，就標記第一關已通過、給予喚名。
  - 已經打完的玩家，更新後直接看到兩關的選關畫面，不必重打十章。
- **下一關的伏筆刻意寫得模糊**：第三關要等玩過第二關才決定，所以寒聲嶺結局對下一個買主只給模糊線索，寒聲的說明也只寫它現在能做什麼，不寫它將來要破什麼。
