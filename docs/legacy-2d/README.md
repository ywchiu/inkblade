# 墨刃 · INKBLADE

可玩的 **2D 橫向水墨格鬥原型**。斗笠劍客「執墨人」依序挑戰墨狼、無相劍客與山魈，也可直接選擇對手自由切磋。

## 開啟遊戲

需要 Node.js（本機以 v25.9.0 驗證），不需安裝任何第三方套件。

```bash
cd /Users/david/personal/game_design/inkblade
npm start
```

用瀏覽器開啟 http://127.0.0.1:4173 。macOS 也可雙擊 `開始遊戲.command` 啟動；伺服器只監聽本機。若 4173 已被使用，可用 `PORT=4174 npm start`。

## 操作

| 按鍵 | 招式 |
| --- | --- |
| A / D 或 ← / → | 左右移動 |
| J（可長按） | 三段刀劍連擊 |
| K | 面向對手格擋；命中前 0.22 秒內按下可彈反 |
| L / Shift | 沿面朝方向閃避，有短暫無敵時間及冷卻 |
| 空白鍵 / ↑ | 跳躍，避開地面震波 |
| I | 墨氣達 100 時施放「墨破山河」 |
| Esc | 暫停 / 繼續 |
| R | 勝敗結算後重新挑戰本卷 |

手機窄螢幕或觸控裝置會顯示虛擬按鈕；可同時按住方向與攻擊。音效預設關閉，右上角可開啟。切換分頁或視窗失去焦點會自動暫停。

## 三場試煉

- **墨狼／竹林：** 快速接近、蓄勢撲擊。閃避後反擊。
- **無相劍客／古寺：** 兩段連斬。掌握格擋與彈反時機。
- **山魈／山門：** 慢速重擊與地面震波。跳躍越過震波，趁收招空檔進攻。

紅圈顯示敵人出招預警，命中與彈反可積蓄墨氣。每卷開始恢復全部生命；三卷全部通過會顯示通關結算。

## 檔案

- `dist/index.html`：首頁、圖鑑、對戰介面。
- `dist/style.css`：宣紙視覺、響應式版面、手機控制。
- `dist/combat.js`：獨立戰鬥模擬、碰撞、敵人 AI、資源與勝敗。
- `dist/game.js`：Canvas 場景與角色、動畫、輸入、合成音效與選單。
- `tests/combat.test.mjs`：戰鬥規則回歸測試。
- `server.mjs`：零外部依賴的本機 HTTP 伺服器。

```bash
npm run check
npm test
```

所有角色、風景、特效皆由程式繪製；不使用外部圖片、字型下載或遊戲素材。文字採本機可用的繁體中文襯線字型。無帳號、連線對戰、後端資料庫或付費 API。
